USAGE RULES
DO:           Use teal (#0D7377) for primary buttons, active nav items, rating numbers, and price text.
DO:           Use white (#FFFFFF) as the dominant background. App is white-first, not cream-first.
DO:           Use Ink (#2C2A25) for all primary body text and headings.
DON'T:      Use teal as a background for large surfaces. Reserve it for the upcoming card and stat blocks only.
DON'T:      Use cream (#F5F0E6) as an in-app background. Cream is for marketing materials and print only.
DON'T:      Mix semantic colors. One status badge per element. No green + gold on the same card.

TYPOGRAPHY RULES
•  All UI text uses Plus Jakarta Sans. No fallback to system fonts in production.
•  Arabic text uses Noto Kufi Arabic. Never mix Arabic and Latin in the same text run.
•  Minimum font size in the app is 9px (tab bar labels). Never go smaller.
•  Teal (#0D7377) for prices, ratings, and active-state text. Ink (#2C2A25) for everything else.
•  Letter-spacing: 0 for body, -0.3px to -0.5px for large titles, +1.5px for uppercase labels.
•  Line height: 1.4 for body text, 1.2 for headings, 1.0 for single-line labels.

Iconography & App Icon
Icon style, navigation, and app store presence
ICON STYLE
•  Stroke-based icons only. No filled icons. 2px stroke weight at 20x20px.
•  Icon source: Lucide Icons (lucide.dev) — consistent with React Native ecosystem.
•  Icon color: #0D7377 (teal) for active/primary, #BBBBBB for inactive, #666666 for neutral.
•  Icon containers: 42x42px rounded squares with #F0FAFA background for home grid actions.
•  Never use emoji as icons. Always use SVG paths.

APP ICON SPECIFICATIONS
•  The app icon uses a teal background (#0D7377) with a white logomark centered.
•  Corner radius follows platform defaults: iOS = continuous superellipse, Android = adaptive.

Brand Voice & Usage
Tone, language, and visual do's and don'ts
BRAND VOICE
Confident, not arrogant.
We know barbers. We don't oversell.
Casual, not sloppy.
Egyptian street energy but polished. Think 'ya basha' not 'dear user'.
Functional, not decorative.
Every word earns its place. No filler copy.
Bilingual, not translated.
Arabic and English are equal. Arabic is not a translation of English.
VISUAL RULES — DO'S
✓    White-dominant backgrounds. Clean, airy layouts. Let content breathe.
✓    Thin borders (1.5px, #E8E8E8) to define cards. No shadows for card elevation.
✓    Teal as a surgical accent — buttons, prices, active states, badges. Not backgrounds.
✓    Functional icons from Lucide. Stroke-only, 2px weight, consistent sizing.
✓    Photography of real haircuts in portfolio sections. No stock photos. No illustrations.
✓    Stats and numbers displayed prominently — visit counts, ratings, prices are first-class.
VISUAL RULES — DON'TS
✗    No glassmorphism, blur effects, or frosted glass. These are AI-generated aesthetics.
✗    No gradients on buttons or cards. Flat solid colors only.
✗    No rounded-everything. Use sharp corners (0px radius) on date-strip underlines and dividers.
✗    No decorative noise textures, grain overlays, or ambient glow effects.
✗    No cream/warm backgrounds inside the app. Cream is for the brand identity, not the UI.
✗    No generic placeholder avatars. Use initials on colored backgrounds (teal or gray).
✗    No emojis in UI (except the greeting wave on the home screen).
MARKETING VS IN-APP
•  Marketing (website, app store, social): Cream (#F5F0E6) backgrounds allowed. Bolder teal usage.
•  In-app UI: White (#FFFFFF) backgrounds only. Teal used sparingly as accent.
•  The dark background (#141310) from the mockup presentation is for design showcases only.
•  App Store screenshots should use the cream background with phone mockups centered.
